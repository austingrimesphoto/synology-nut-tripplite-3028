# Security and safety reporting

Treat defects that can cause an unexpected shutdown, prevent safe-mode entry, disable UPS monitoring, or execute UPS output-control commands as safety-sensitive.

For ordinary compatibility bugs, open a GitHub issue. For vulnerabilities that should not be public before a fix is available, use GitHub private security advisories if enabled.

Do not include passwords, NAS credentials, SSH keys, UPS serial numbers, or other secrets in reports.
